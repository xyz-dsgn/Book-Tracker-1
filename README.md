# Book-Tracker
Программа для списка прочитанных книг

**Автор:** Елизавета Недолужко

## Описание программы 
Программа для управления списком прочитанных книг. Позволяет добавлять книги, фильтровать их по жанру и количеству страниц, сохранять и загружать данные в формате JSON.
## Требования для запуска 
Что нужно установить на компьютер: - Python 3.10 или выше - Библиотеки: `pip install tkinter`
## Как запустить 
```bash 
git clone https://github.com/xyz-dsgn/Book-Tracker-1
cd Book-Tracker-1
python main.py
```
## Как пользоваться 
- Добавьте книгу через форму и нажмите «Добавить книгу».
- Используйте фильтры для поиска по жанру или минимальному количеству страниц.
- Данные сохраняются автоматически при добавлении книги.
## Пример работы 
1. Вы запускаете программу и видите окно с полями для добавления книги и таблицей.
2. Вводите новую книгу:
• Название книги: «Три товарища»
• Автор: «Эрих Мария Ремарк»
• Жанр: «Роман»
• Страниц: 480
3. Нажимаете «Добавить книгу» — книга появляется в списке.
4. В поле «Фильтр по жанру» вводите «Роман» и нажимаете «Применить фильтр» — в таблице показываются только книги жанра «Роман».
5. В поле «Мин. страниц» вводите «450» и нажимаете «Применить фильтр» — осталась только «Три товарища».
